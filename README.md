# 🎬 NigerCut – AI-Powered Short-Form Video Editor

[![Flutter](https://img.shields.io/badge/Flutter-3.x-blue.svg)](https://flutter.dev)
[![License](https://img.shields.io/badge/License-Proprietary-red)](LICENSE)

**NigerCut** is a premium, AI‑enhanced short‑form video editor built by **Zetra Systems**.  
It is designed to feel like a natural extension of the **NigerGram** ecosystem – dark, glassmorphic, smooth, and professional.

> ⚡ **Key Features** – Smart auto‑cutting, AI‑suggested transitions, real‑time preview, and export at 120fps.

---

## ✨ Design Philosophy

- **Dark UI** – Deep blacks (`#0D0D0D`) with soft surfaces (`#181818`)
- **Emerald Accent** – Signature green (`#00C853`) for primary actions and highlights
- **Glassmorphism** – Frosted glass effects with blur, subtle borders, and soft shadows
- **Smooth Animations** – Optimised for 120fps, with `easeInOut` curves
- **NigerGram Integration** – All visual elements are consistent with **NigerGram** to provide a unified user experience across Zetra Systems' products
